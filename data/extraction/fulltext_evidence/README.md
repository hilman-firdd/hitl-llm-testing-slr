# Full-text evidence per re-coded study

One file per study that was first coded from its abstract and later read in full (26 October 2026). Each file lists the human
actions, timing, and evaluation design found in the full text, with the section number in brackets.

- Passages were extracted with AI assistance (Claude, Anthropic); the first author checked the coding that rests on them
  (see `../fulltext_recoding_log.csv`).
- Quotations are kept short (under 15 words); a longer passage is cut and marked `[...]`. Open the cited section of the paper
  (DOI in `../extraction_quality.csv`) for the complete text.
- `aranda2025.md` documents the one study that was excluded after reading the full text (EC3).
